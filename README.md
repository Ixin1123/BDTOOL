# BD报文抓取与自动截图工具

一款专为北斗定位日志分析打造的轻量级自动化工具。旨在通过程序自动抓取核心报文并生成规范的结论截图，告别繁琐的手动翻找与截图，大幅提升日常质检与取证的工作效率。

## ✨ 核心功能
* **自动化抓取**：一键载入 NMEA 日志文件，快速锁定并提取目标时刻的核心报文段落。
* **智能判定**：支持手动指定时间提取“定位成功”报文，或全自动检索提取典型的“定位失败”报文。
* **极速出图**：自动将解析出的报文片段与判定结论生成 `.png` 图片，并统一保存在源日志的同级目录下。

## 🚀 快速上手
1. 双击运行打包好的 `.exe` 程序（无需额外配置 Python 环境）。
2. 点击 **载入 NMEA 日志文件**，选择需要分析的文件。
3. （可选）手动输入需要核查的时间戳。如果不填，系统将自动寻找并提取定位失败的片段。
4. 点击 **生成取证截图**，即可在同目录下获取自动生成的图片。

## 🔄 最新版本更新说明 (2026/4/7)

针对前期在实际质量检验测试中遇到的环境兼容性与设备协议多样性问题，本版本进行了深度的底层逻辑重构与业务话术规范化：

### 1. 📝 检验术语严格规范化
* **改动**：将取证图片与系统提示中的“定位成功 / 定位失败”全面替换为**“定位正常 / 定位异常”**。
* **价值**：摒弃口语化表达，严格对齐国家级质检机构及产品测试的专业规范用语，提升了自动生成证据链的严谨性与专业度。

### 2. 🌐 多模协议自适应解析（核心架构升级）
* **改动**：移除了对特定 Talker ID（如 `$GNRMC`、`$BDRMC`）的硬编码依赖，重构为基于 NMEA 0183 核心报文类型（`RMC` / `GGA`）的模糊匹配算法。
* **价值**：打破了不同硬件厂商、不同模组（单北斗 `$BD`、多模 `$GN`、甚至其他新前缀如 `$GB`）带来的解析壁垒。如今，只要报文结构符合规范，系统即可实现 100% 兼容与盲抓，极大拓宽了工具的适用终端范围。

### 3. 🖥️ 老旧系统环境渲染兼容（彻底解决中文乱码）
* **改动**：针对部分老旧办公设备（如 Windows 7 环境）下，Matplotlib 绘图导出图片出现“中文方块/豆腐块”的问题，重构了**三层防线字体加载机制**（全局字体参数注入 + `.ttf` 物理路径扩充 + 强制字体族回退）。
* **价值**：无需在宿主机上进行任何手动字体安装或环境配置，确保了跨平台、跨系统版本的“开箱即用”与中文 100% 完美渲染，保障了检验任务在各类办公环境下的顺利推进。

### 4. 🔍 “定位异常”智能溯源逻辑优化
* **改动**：在自动寻找无效定位状态的功能中，将识别条件放宽至“全局检索包含无效标识位（`,V,`）的所有 `RMC` 报文”。
* **价值**：与自适应协议升级相辅相成，即便送检设备在异常状态下前缀发生跳变，系统依然能精准锁定并截取该故障时刻的完整报文对，为排查设备定位缺陷提供可靠证据。
