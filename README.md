# BD报文抓取与自动截图工具

一款专为北斗定位日志分析打造的轻量级自动化工具。旨在通过程序自动抓取核心报文并生成规范的结论截图，告别繁琐的手动翻找与截图，大幅提升日常质检与取证的工作效率。

## ✨ 核心功能
* **自动化抓取**：一键载入 NMEA 日志文件，快速锁定并提取目标时刻的核心报文段落。
* **智能判定**：支持手动指定时间提取“定位成功”报文，或全自动检索提取典型的“定位失败”报文。
* **极速出图**：自动将解析出的报文片段与判定结论生成 `.png` 图片，并统一保存在源日志的同级目录下。

## 🚀 快速上手
1. 双击运行打包好的 `.exe` 程序（无需额外配置 Python 环境）。
2. 点击 **载入 NMEA 日志文件**，选择需要分析的文件。
3. （可选）手动输入需要核查的时间戳。如果不填，系统将自动寻找并提取定位失败的片段。
4. 点击 **生成取证截图**，即可在同目录下获取自动生成的图片。
